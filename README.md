# بنك الحظ المصري — إصدار النخبة 🎲

لعبة متصفح عربية باتجاه RTL، بطابع مصري وخصوم آليين. تعمل على الهاتف والكمبيوتر من دون تسجيل حساب أو تثبيت.

## المميزات
- أربعة لاعبين: أنت وثلاثة منافسين آليين.
- لوحة من 40 خانة بأسماء شوارع ومدن ومعالم مصرية.
- شراء العقارات وتحصيل الإيجارات ومحطات النقل والمرافق.
- بطاقات الحظ والضرائب والسجن والإفلاس.
- تطوير العقارات ورهن الأملاك وفك الرهن.
- نرد متحرك وحركة تدريجية للقطع على اللوحة.
- مؤثرات صوتية اختيارية يمكن تشغيلها أو إيقافها.
- حفظ تلقائي للتقدم على الجهاز واستعادة المباراة عند فتح الصفحة مجددًا.
- زر حفظ يدوي، وواجهة عربية متجاوبة.
- اختصارات لوحة المفاتيح: Space لرمي النرد، Enter لإنهاء الدور، S للحفظ، وEscape لإغلاق النافذة.
- فحص صياغة JavaScript تلقائيًا قبل النشر عبر GitHub Actions.

## اللعب
افتح [اللعبة المنشورة](https://arkanws513-spec.github.io/Bank-elhaz/). يعمل الحفظ على الجهاز والمتصفح نفسه، وقد لا ينتقل إلى جهاز آخر أو وضع التصفح الخاص.

## التشغيل المحلي
افتح `index.html` في متصفح حديث، أو شغّل خادم ملفات ثابتة محليًا.

## ملاحظات
هذه لعبة مستقلة مستوحاة من ألعاب شراء العقارات، وليست إصدارًا رسميًا أو إعادة إنتاج حرفية للعبة تجارية. لا يوجد حاليًا لعب جماعي عبر الإنترنت.
