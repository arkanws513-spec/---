# بنك الحظ المصري — إصدار النخبة

لعبة متصفح عربية باتجاه RTL، مستوحاة من ألعاب شراء العقارات الكلاسيكية، مع لوحة بطابع مصري وخصوم آليين.

## التشغيل
افتح `index.html` في متصفح حديث، أو استخدم GitHub Pages لاستضافة اللعبة.

## المميزات الحالية
- أربعة لاعبين: أنت وثلاثة منافسين آليين.
- لوحة من 40 خانة بطابع مصري.
- شراء العقارات، الإيجارات، محطات النقل والمرافق.
- بطاقات الحظ، الضرائب، السجن، والإفلاس.
- تطوير العقارات، رهن الأملاك وفك الرهن.
- واجهة عربية متجاوبة مع الهواتف.
- لا توجد حاجة إلى خادم أو قاعدة بيانات.

## ملاحظة
هذه لعبة مستقلة مستوحاة من آلية ألعاب شراء العقارات، وليست إصدارًا رسميًا أو إعادة إنتاج حرفية للعبة تجارية. الأرصدة وحالة المباراة لا تُحفظ بعد إغلاق الصفحة.
